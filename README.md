# python-sales-analysis
# E-commerce Sales & Customer Analytics

## Project Overview

This portfolio project focuses on analyzing online store sales using SQL, Python, Google BigQuery, and Tableau.

The project includes data extraction from BigQuery, exploratory data analysis (EDA), sales and customer behavior analysis in Python, and interactive dashboard development in Tableau.

The dataset combines:

* sales transactions,
* customer sessions,
* traffic sources,
* device and browser information,
* product categories,
* user account data.

---

* Tableau Public

* SciPy
* Statsmodels

---

## Project Analysis

The analysis explores:

* sales trends and seasonality,
* top-performing countries and continents,
* product category performance,
* traffic channel analysis,
* device and browser analytics,
* customer subscription and verification behavior,
* customer segmentation,
* sales dynamics over time.

The project also includes:

* missing value analysis,
* pivot tables,
* correlation analysis,
* KPI reporting,
* business insights visualization.

---

## Dashboard Overview

The Tableau dashboard visualizes:

* total sales and sessions,
* regional sales distribution,
* traffic channel performance,
* sales by device and browser,
* top-selling product categories,
* sales trends over time.

The dashboard was designed to support business-oriented decision-making and customer behavior analysis.
